产品 01

室内设计 Agent（暗壳AI）

项目背景

面向室内设计师、家具品牌与企业设计团队，建设覆盖“设计需求理解—方案规划—空间效果生成—商品匹配—视频资产生产—交易履约”的智能空间设计系统。针对传统设计流程中需求沟通成本高、方案生产周期长、专业工具门槛高，以及设计方案与真实商品供应链割裂等问题，主导构建具备意图理解、任务拆解、自主推理和工具调度能力的空间设计 Agent，并连接 3000+ 品牌家具供应链，让设计创意能够进一步转化为可选购、可交付的商业方案。

核心产品能力

  • 设计需求理解：通过多轮对话识别空间类型、户型条件、设计风格、预算、居住人群与功能诉求，将“现代、温馨、有高级感”等模糊表达转化为空间布局、材质、色彩、家具和灯光等结构化设计约束。
  • 空间设计 Agent：规划需求澄清、知识检索、方案推理、工具调用与结果校验链路，由 Agent 根据任务自主选择空间生成、局部改造、商品替换和方案优化等 Skills，形成从用户意图到设计结果的完整执行闭环。
  • 三级知识库与记忆：从 0 到 1 设计行业、企业、项目三级知识体系。行业库沉淀设计规范、风格与空间方法；企业库管理品牌商品和业务规则；项目库记录客户需求、历史方案与修改反馈，增强知识检索、上下文记忆及企业级定制能力。
  • 设计交易与供应链：将生成方案中的家具、建材与真实 SKU 进行匹配，规划商品推荐、清单管理、订单管理和 ERP 履约链路，打通“AI 设计生成—实景导购—下单采购—交付履约”的设计交易闭环。
  • 多模态视频资产：主导视频生成模型评测与选型，完成 Seedance 2.0、Happy Horse 1.0 等模型接入，将静态空间方案延伸为动态展示视频，并围绕镜头一致性、空间结构稳定性、运动自然度与音画同步持续优化生成效果。

Agent 评测机制

  • 意图理解评测：评估空间信息提取、模糊需求澄清、约束识别与上下文记忆的准确性，验证 Agent 是否真正理解用户想解决的设计问题。
  • 任务规划评测：围绕任务拆解、Skills 选择、工具路由、参数传递和异常降级建立 Benchmark 测试集，检查执行链路是否合理、稳定且可恢复。
  • 结果质量评测：从空间结构合理性、风格一致性、视觉质量、商品可匹配性和方案可落地性评估输出，并通过人工评审与模型评测结合降低单一指标偏差。
  • 迭代闭环：对失败任务进行 Badcase 分类，定位知识缺失、Prompt 策略、模型能力或工具调用问题，将结果回流至知识库、测试集和产品策略，形成“评测—反馈—优化—回归测试”的持续迭代机制。

项目成果

  • 建立空间设计 Agent 标准化评测与持续优化机制
  • 完成行业、企业、项目三级知识库架构落地
  • 打通设计生成、商品推荐至 ERP 履约核心链路

核心产品能力

  • C–P–B 三端协同：消费者获得个性化方案，设计师参与专业服务与方案优化，品牌商提供真实商品和履约能力，形成平台化协作关系。
  • 设计交易闭环：通过 AI 实景导购将方案中的家具、建材与商城 SKU 关联，打通“设计生成—商品推荐—清单确认—下单购买”链路。

产品 03

观境 GUANJING · 入境城市旅行 Agent

项目背景

面向来华入境游客，建设覆盖“旅行灵感发现—需求理解—行程规划—旅中伴游—内容资产沉淀”的智能城市旅行系统。产品以北京、深圳、成都、上海、西安、广西等重点目的地为核心，整合城市文化、景点、美食、交通与服务信息，并设计城市推荐 Agent、行程规划 Agent、旅中伴游 Agent 和旅行内容生成 Agent，帮助游客降低跨语言、跨文化环境下的信息检索与决策成本，获得更具在地感且可执行的中国旅行方案。

核心产品能力

  • 入境游客需求理解：通过多轮对话识别出发地、旅行天数、预算、兴趣、同行关系、饮食禁忌与语言偏好，将“想体验真实中国”等模糊诉求转化为可计算的旅行约束和任务目标。
  • 城市旅行知识库：搭建覆盖城市文化、景点、美食、交通、营业时间、预约规则与入境服务的目的地知识体系；结合 RAG 与结构化标签，建立城市—区域—主题—地点—体验之间的关联，为回答提供可追溯的在地信息。
  • 多城市行程规划：综合开放时间、地点距离、交通耗时、游览节奏与用户偏好，生成按天、按时段组织的可执行路线；当预算、天气或营业状态变化时，Agent 可识别冲突并动态调整方案。
  • 旅中伴游与工具调用：围绕“现在去哪、怎么去、吃什么、如何沟通”等即时问题提供上下文连续的陪伴服务，并为地图导航、天气查询、交通换乘、门票预约与翻译等工具预留调用链路。
  • 旅行内容资产生成：将城市知识与用户行程转化为目的地卡片、路线故事、文化讲解及短视频脚本，沉淀可复用的城市内容资产，支持北京、深圳、成都、上海、西安、广西等目的地持续扩展。

Agent 评测机制

  • 知识检索评测：评估城市信息检索命中率、事实准确性、引用一致性、时效性与错误信息拦截能力。
  • 规划质量评测：从偏好匹配、时间可行性、路线合理性、预算符合度与文化体验丰富度建立测试集，并通过 Badcase 回流持续优化 Prompt 与规划策略。
  • Agent 执行评测：验证意图识别、任务拆解、上下文记忆、工具选择、参数传递及异常降级是否正确，避免出现行程冲突和不可执行建议。
  • 端到端体验评测：结合行程采纳、用户修改、任务完成、内容收藏及正负向反馈，判断系统是否真正缩短规划时间并提升入境旅行体验。

项目成果

  • 完成入境旅行 Agent 产品原型与核心交互闭环
  • 建立六大重点目的地的城市内容框架
  • 形成从知识检索到行程生成的评测体系

AI 项目管理投资决策平台

项目背景

针对政府数据不通、申报流程冗长等痛点，AI 辅助审查和决策。负责年度投资项目 AI 评估入库、债券资金申请评估、项目双算 AI 审核三大模块，100+ 项目数据治理，规则引擎 Skills + RAG 为核心。

核心产品模块

  • 智能审查：将复杂审批规则转化为规则引擎 Skills，支持年度投资项目评估入库、债券资金申请评估与项目双算审核。
  • 建设监测：多模态解析施工文本，自动抽取工序和工期，生成甘特图及项目报告。
  • 知识问答：以 RAG 为核心构建建筑规范与历史项目知识库，为项目审查和决策提供可溯源的专业问答。
  • 决策 Agent：非审查模块采用 AI Agent + MCP 编排多步骤任务，自动生成决策参考。

RAG 知识问答模块

  • 治理 1000+ 专业设计规范、方案与设计指引，采用重叠分块与 Embedding 构建向量检索链路。
  • 通过 Query 重写、RAG Fusion 与 Rerank 优化召回率、准确率和答案语义连贯性。
  • 建立 500+ 标准问答测试集，覆盖准确率、召回率、响应时间与引用有效性等指标。

项目成果
