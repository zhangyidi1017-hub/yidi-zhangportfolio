产品 02

室内设计 Agent（暗壳AI）

项目背景

面向室内设计师、家居品牌与企业设计团队，建设覆盖“设计需求理解—方案规划—空间效果生成—商品匹配—交易履约”的智能空间设计系统。针对传统设计流程中需求沟通成本高、方案生产周期长、专业工具门槛高，以及设计方案与真实商品供应链割裂等问题，主导构建具备意图理解、任务拆解、自主推理和技能调用能力的空间设计 Agent，并连接 3000+ 家居品牌供应链，让设计创意能够进一步转化为可选购、可交付的商业方案。

核心产品能力

  • 设计需求理解：通过多轮对话识别空间类型、户型条件、设计风格、预算、居住人群与功能诉求，将“现代、温馨、有高级感”等模糊表达转化为空间布局、材质、色彩、家具和灯光等结构化设计约束。
  • 空间设计 Agent：规划需求澄清、知识检索、方案推理、技能调用与结果校验链路，由 Agent 根据任务自主选择空间生成、局部改造、商品替换和方案优化等 Skills，形成从用户意图到设计结果的完整执行闭环。
  • 三级知识库与记忆：从 0 到 1 设计行业、企业、项目三级知识体系。行业库沉淀设计规范、风格与空间方法；企业库管理品牌商品和业务规则；项目库记录客户需求、历史方案与修改反馈，增强知识检索、上下文记忆及企业级定制能力。
  • 设计交易与供应链：将生成方案中的家具、建材与真实 SKU 进行匹配，规划商品推荐、清单管理、订单管理和 ERP 履约链路，打通“AI 设计生成—实景导购—下单采购—交付履约”的设计交易闭环。

业务场景与完整链路

典型场景：一位首次到上海的入境游客，希望用两天了解城市更新与当代艺术，但不了解不同街区的文化脉络、近期展览及空间之间的关系。

  • 1. 灵感发现：产品先通过城市空间、近期展览和主题体验卡片呈现目的地内容，不以热门景点榜单作为唯一入口，帮助用户从“上海有什么”逐步聚焦到“城市更新 + 当代艺术”的旅行主题。
  • 2. 需求澄清：Agent 继续询问旅行日期、可用时长、文化兴趣、语言、步行接受度和体验深度，并识别“希望理解城市而非打卡”等隐性诉求，形成主题权重、时间边界和空间偏好的结构化任务。
  • 3. 知识检索：根据任务并行检索城市空间库与展览文化库，召回相关建筑、街区、艺术机构、当前展览和文化活动；通过 RAG 补充历史背景、设计脉络、策展主题、开放时间与信息来源，过滤过期或缺乏依据的内容。
  • 4. 主题路线生成：规划 Agent 根据内容关联、地理距离、开放时段和参观节奏进行任务编排，将零散地点组织为“西岸滨水工业更新—艺术机构—当代展览”等有叙事逻辑的路线，并给出每站推荐理由、停留时间和前后关系。
  • 5. 行程可执行校验：系统检查闭馆、预约冲突、跨区耗时和路线折返；天气、交通、餐饮等信息仅在影响执行时参与调整，例如雨天减少户外空间、闭馆时替换同主题展览，而不改变文化体验主线。
  • 6. 旅中文化讲解：用户抵达空间或展览后，Agent 基于当前地点和已浏览内容提供分层讲解，回答“为什么这里重要”“它与上一站有什么关系”等追问，并保持跨地点的上下文记忆。
  • 7. 反馈与内容回流：收藏、跳过、路线修改和讲解反馈被用于更新用户兴趣与内容质量判断；高价值讲解沉淀为城市卡片、空间导览和短视频脚本，缺失或过期信息进入知识库补充与复核流程。

Agent 评测机制

  • 意图理解评测：评估空间信息提取、模糊需求澄清、约束识别与上下文记忆的准确性，验证 Agent 是否真正理解用户想解决的设计问题。
  • 任务规划评测：围绕任务拆解、Skills 选择、技能路由、参数传递和异常降级建立 Benchmark 测试集，检查执行链路是否合理、稳定且可恢复。
  • 结果质量评测：从空间结构合理性、风格一致性、视觉质量、商品可匹配性和方案可落地性评估输出，并通过人工评审与模型评测结合降低单一指标偏差。
  • 迭代闭环：对失败任务进行 Badcase 分类，定位知识缺失、Prompt 策略、模型能力或技能调用问题，将结果回流至知识库、测试集和产品策略，形成“评测—反馈—优化—回归测试”的持续迭代机制。

项目成果

  • 建立空间设计 Agent 标准化评测与持续优化机制
  • 完成行业、企业、项目三级知识库架构落地
  • 打通设计生成、商品推荐至 ERP 履约核心链路

产品 03

AI 实景导购小程序

项目背景

基于暗壳空间设计 Agent，规划面向家居品牌与线下卖场的 B 端 AI 导购小程序，服务三棵树、东鹏瓷砖、红星美凯龙卖场等商家。产品帮助导购将消费者的真实空间快速转化为商品应用效果，通过一键替换墙面材质、瓷砖或家具，让客户在购买前直观看到搭配结果，并将效果方案直接关联至商家真实商品 SKU，缩短从选品、体验到采购的决策链路。

核心产品能力

  • B 端商品接入：将品牌涂料、瓷砖、家具等商品素材与 SKU 建立关联，形成可被 Agent 检索、推荐和调用的商家商品库，支持不同品牌与卖场快速配置专属导购内容。
  • 一键换材与换家具：导购上传客户空间照片后，可选择墙面、地面或家具区域，一键替换为三棵树涂料、东鹏瓷砖或卖场家具商品，快速生成贴近真实空间的应用效果。
  • AI 场景化导购：根据客户空间条件、风格偏好和选购需求推荐适配商品，通过效果对比与组合搭配辅助导购讲解，降低客户对材质、尺寸和整体效果的理解成本。
  • 一键采购闭环：将客户确认的材质与家具自动映射至商品 SKU，生成商品清单并连接采购入口，打通“空间上传—效果替换—方案确认—SKU 清单—一键采购”的完整链路。
产品 01

观境 GUANJING · 城市文化体验 Agent

项目背景

面向希望深入理解中国城市的入境游客，建设以“城市空间—城市展览—文化体验”为核心的智能旅行产品。产品覆盖北京、深圳、成都、上海、西安、广西等重点目的地，通过城市文化知识库与 Agent，将建筑、街区、艺术机构、博物馆、展览和在地文化活动组织成可探索、可理解、可执行的主题体验；天气、美食、交通等通用旅行信息作为辅助条件，为文化行程提供必要的决策支持。

核心产品能力

  • 文化兴趣理解：通过多轮对话识别用户对建筑、城市更新、当代艺术、历史遗产、设计、表演与地方生活等主题的偏好，将“想看真实的城市”“想了解当地文化”等模糊诉求转化为主题、空间类型、体验深度和时间节奏等规划条件。
  • 城市空间知识库：围绕地标建筑、历史街区、城市公共空间、更新项目与社区场所组织知识，记录空间背景、设计脉络、历史变化、开放规则和周边关系，帮助用户理解地点，而不只是抵达地点。
  • 展览与文化体验知识库：持续沉淀博物馆、美术馆、画廊、艺术园区、临时展览、演出和非遗体验等内容；结合 RAG 与结构化标签，建立“城市—区域—主题—机构—展览—人物—时代”的关联，并保留来源与时效信息。
  • 主题路线规划：根据文化兴趣、空间距离、开放时间与体验节奏，将分散的城市内容组合为建筑观察、艺术展览、历史街区或地方文化等主题路线；天气、交通、预约和餐饮仅作为路线可执行性的辅助约束。
  • 文化内容资产生成：将知识库内容转化为城市卡片、空间导览、展览推荐、文化讲解、路线故事及短视频脚本，形成可持续复用的内容资产，并支持重点目的地逐步扩展。

Agent 评测机制

  • 知识检索评测：评估空间、展览与文化内容的检索命中率、事实准确性、来源一致性、内容时效性和知识关联完整度。
  • 内容质量评测：从文化解释准确性、信息密度、主题相关性、在地独特性和表达易懂度建立测试集，避免输出泛化、同质化的城市介绍。
  • 规划质量评测：评估主题匹配、空间关联、时间可行性、路线合理性与文化体验丰富度，并通过 Badcase 回流持续优化检索、Prompt 和规划策略。
  • Agent 执行评测：验证意图识别、任务拆解、上下文记忆、工具选择、参数传递及异常降级是否正确，避免出现行程冲突和不可执行建议。
  • 端到端体验评测：结合行程采纳、用户修改、任务完成、内容收藏及正负向反馈，判断系统是否真正缩短规划时间并提升入境旅行体验。

项目成果

  • 完成城市文化体验 Agent 产品原型与交互闭环
  • 建立六大重点目的地的空间与文化内容框架
  • 形成从文化知识检索到主题路线生成的评测体系

AI 项目管理投资决策平台

项目背景

针对政府数据不通、申报流程冗长等痛点，AI 辅助审查和决策。负责年度投资项目 AI 评估入库、债券资金申请评估、项目双算 AI 审核三大模块，100+ 项目数据治理，规则引擎 Skills + RAG 为核心。

核心产品模块

  • 智能审查：将复杂审批规则转化为规则引擎 Skills，支持年度投资项目评估入库、债券资金申请评估与项目双算审核。
  • 建设监测：多模态解析施工文本，自动抽取工序和工期，生成甘特图及项目报告。
  • 知识问答：以 RAG 为核心构建建筑规范与历史项目知识库，为项目审查和决策提供可溯源的专业问答。
  • 决策 Agent：非审查模块采用 AI Agent + MCP 编排多步骤任务，自动生成决策参考。

RAG 知识问答模块

  • 治理 1000+ 专业设计规范、方案与设计指引，采用重叠分块与 Embedding 构建向量检索链路。

  • 建立 500+ 标准问答测试集，覆盖准确率、召回率、响应时间与引用有效性等指标。
