# 张贻娣 — AI 产品经理作品集

参考 [Wildy Riftian](https://www.wildyriftian.com/) 档案风设计与交互，展示 AI 产品经理个人作品与经历。

## 启动

```bash
npm install
npm run dev
```

浏览器访问 http://localhost:3000

## 构建

```bash
npm run build
npm run preview
```

## 页面结构

- **首页** — 档案风 Hero、分类轮播、文件夹 3D 视觉
- **关于** — 个人简介、工作经历、教育背景、核心技能
- **作品** — 五个 AI 产品项目；RAG 知识问答作为投资决策平台的核心模块统一呈现
- **联系** — 邮箱、电话、微信

## 技术栈

- Vite
- 原生 HTML / CSS / JavaScript
- Intersection Observer 滚动动画
- 响应式布局
